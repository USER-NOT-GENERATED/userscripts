## 00 Userscripts
- Tampermonkey userscripts, tested in Zen (Firefox based)
- Install: open the raw `*.user.js` link, Tampermonkey shows the install page
- Updates: Tampermonkey checks `@updateURL` and installs a higher `@version`

## 01 Scripts
- `save-page.user.js`: saves the current page as one self-contained HTML file, Alt+Shift+S or the Tampermonkey menu
- `booth-keywords-dark.user.js`: counts and highlights VRoid / facial-rig terms on BOOTH, dark mode
- `zai-layout.user.js`: chat.z.ai wider message column and input (about 1300 px), the input keeps the height of its text instead of collapsing to two lines
- `zai-wording.user.js`: chat.z.ai button that puts a prepared text into the chat input; no auto-update, edit the text in Tampermonkey
